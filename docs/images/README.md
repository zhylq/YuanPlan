## 架构图

`architecture/yuanplan-architecture.png` 为展示文件，同名 SVG 为可编辑矢量源文件。图示当前单实例结构：浏览器与外部 AI 客户端、部署方配置的 HTTPS 代理、Node.js / Hono 应用、共用业务服务、PostgreSQL、附件持久化与运维 CLI。可选 stdio 桥接在外部客户端一侧。

更新配图时应使用新的合成演示数据，并核对图片中的账号、地址和凭据，避免带入真实实例信息。项目代码与这些原创配图使用仓库 MIT 许可证。

英文 README 使用 `architecture/yuanplan-architecture.en.png` 与同名 SVG；两种语言的架构图结构一致，仅翻译文字标签。页面截图仍为中文界面，英文 README 已作说明。
